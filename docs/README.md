# Dodge Box

Dodge Box is an arcade survival game created for CSCI 4160U Game Development.

## Description

The player controls a box and must avoid enemy boxes for as long as possible. The player's score increases based on survival time, and the difficulty increases as the game progresses.

## Controls

- W / Up Arrow - Move Up
- S / Down Arrow - Move Down
- A / Left Arrow - Move Left
- D / Right Arrow - Move Right
- R - Restart the game after losing

## Requirements

- Windows PC
- Odin
- Raylib

## How to Run

1. Install Odin.
2. Clone or download this repository.
3. Open a terminal in the project folder.
4. Run the project using:

   `odin run .`

5. The game will launch in a new window.
