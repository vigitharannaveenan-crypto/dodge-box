
# Dodge Box - Postmortem

**Student:** Naveenan Vigitharan  
**Course:** CSCI 4160U - Game Development

## Project Status

The project is currently in the documentation and game design phase.

The initial Dodge Box concept involved controlling a square and avoiding moving enemies.

Following feedback from the teaching assistant, the design was expanded to include:

- Four enemy types with different behaviours.
- Four levels with increasing difficulty.
- Multiple arena layouts.
- Obstacles and more challenging gameplay.
- A scoring and progression system.
