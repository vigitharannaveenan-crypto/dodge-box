
# Dodge Box

Dodge Box is a 2D arcade survival game designed for CSCI 4160U Game Development.

## Game Description

The player controls a blue square and must avoid different types of enemies while surviving increasingly difficult levels.

The game will feature four levels, multiple enemy types, different arena layouts, and a scoring system.

## Planned Enemy Types

- Basic Enemy: Moves in a straight line at a normal speed.
- Fast Enemy: Moves faster and requires quicker reactions.
- Chaser Enemy: Follows the player's position.
- Heavy Enemy: Larger and slower, making it harder to move around.

## Planned Levels

### Level 1 - Training Arena
- Open arena
- Basic enemies
- Survive for 20 seconds

### Level 2 - Speed Arena
- Basic and fast enemies
- Increased movement speed
- Survive for 25 seconds

### Level 3 - Chase Arena
- Basic, fast, and chaser enemies
- Stationary obstacles
- Survive for 30 seconds

### Level 4 - Final Arena
- All four enemy types
- Smaller arena with obstacles
- Survive for 35 seconds

## Planned Features

- WASD and arrow-key movement
- Collision detection
- Survival-based scoring
- Multiple enemy behaviours
- Increasing difficulty
- Level progression
- Game-over and victory screens
- Restart option

## Controls

- W / Up Arrow: Move up
- S / Down Arrow: Move down
- A / Left Arrow: Move left
- D / Right Arrow: Move right
- R: Restart after winning or losing
